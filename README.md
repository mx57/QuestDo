## 🎯 Философия продукта

Классические To-Do списки вызывают **когнитивный паралич**: когда человек видит перед собой 100, 500 или 2000 накопившихся задач, мозг воспринимает это как угрозу и уходит в прокрастинацию.

**QuestDo** решает эту проблему фундаментально:
1. **Принцип микро-уровней:** Приложение прячет весь массив бэклога и выводит на экран **только 2–3 задачи** текущего уровня (Quest).
2. **Игровая изоляция:** Следующие задачи не видны, пока не закрыт текущий уровень. Фокус максимален, тревожность равна нулю.
3. **Реальный и виртуальный дофамин:** Закрытие уровня награждается золотыми монетами, очками опыта (XP) и правом активировать реальную награду (чашка кофе, 15 минут сериала, отдых).
4. **Анти-токсичность:** Никаких угрожающих красных экранов и штрафов. Приложение поддерживает, помогает начать с микро-шага и позволяет мягко перетасовать уровень.

## ✨ Ключевые возможности

### 🎮 1. Система микро-квестов
- **Умное разделение:** Интеллектуальный алгоритм отбирает задачи из бэклога по матрице Эйзенхауэра и формирует компактные уровни.
- **Настройка сложности:** Выбирайте сами комфортный темп — 1, 2, 3 или 5 задач на один квест.
- **Празднование победы:** Анимированный сундук с сокровищами, вылетающие частицы конфетти и тактильная отдача.
- **Система серий (Streaks):** Трекинг непрерывных дней активности с огоньком 🔥 и фиксацией рекорда.

### 🧠 2. Психологическая среда и 4 Муда (Настроения)
Интерфейс мгновенно адаптирует палитру, тональность цитат и советы под ваше состояние:
- 🎯 **«Фокус»** — глубокий индиго и кобальт, цитаты о концентрации и глубокой работе.
- 🌿 **«Спокойствие»** — пастельный шалфей и мята, антистресс и дыхательные упражнения.
- ⚡ **«Преодоление»** — энергия воина, пламенный янтарь, дисциплина и сокрушение преград.
- 💖 **«Забота о себе»** — нежная розовая палитра, напоминания о воде, осанке и отдыхе без вины.

### 🛡️ 3. Анти-прокрастинационный SOS-модуль
- **«Правило 2 минут»** и **«Правило 5 секунд»**: проверенные психологические техники быстрого старта.
- **Дыхательный тренажер «Квадрат 4-4-4-4»**: анимированный пульсирующий круг для мгновенного снятия тревоги перед сложной задачей.
- **Мягкая перетасовка квеста:** Застряли? Смените задачи текущего уровня в 1 тап без потери серии и штрафов.

### 🎁 4. Экономика наград и прокачка Героя
- **Профиль Героя:** Рост уровней, прогресс-бар XP и почетные титулы («Искатель продуктивности», «Владыка потока», «Легенда баланса»).
- **Магазин вознаграждений:** Тратьте заработанные монеты 🪙 на приятные вещи в реальной жизни.
- **Конструктор личных наград:** Создавайте свои собственные награды с кастомными ценами и эмодзи.
- **Зал славы и ачивки:** Разблокируйте бейджи за серии, ночную продуктивность и глубокие сессии.

### ⏱️ 5. Интегрированный Фокус-таймер (Pomodoro)
- Запуск таймера непосредственно на выбранную задачу квеста.
- Предустановленные режимы (15, 25, 45 минут) с круговым неоновым прогресс-баром.
- **Фоновые звуковые атмосферы:** Анимированный визуализатор звуковых волн с режимами: *Шум дождя 🌧️*, *Белый шум 📻*, *Костер 🔥*, *Космос 🌌*, *Тишина 🤫*.
- Начисление бонусных монет и XP за время, проведенное в потоке.

### 📋 6. Мощный органайзер задач (Backlog Engine)
- **Матрица Эйзенхауэра:** Приоритеты Q1 (Срочно/Важно), Q2 (Важно), Q3 (Делегировать), Q4.
- **Чек-листы:** Неограниченные вложенные подзадачи с быстрым добавлением.
- **Массовый импорт (Bulk Import):** Вставьте сотни строк из заметок или выберите готовые паки («Life RPG», «IT Проект») — приложение само распределит их по будущим квестам.
- **Мгновенный поиск и архив:** Полная история выполненных подвигов.

### 📅 7. Календарь и аналитика
- Интерактивная полоса дней недели для планирования квестов вперед.
- Аналитика продуктивности по времени суток (Утро, День, Вечер, Ночь).
- Общая статистика выполненных задач, закрытых квестов и времени в фокусе.

### 🎨 8. Кастомизация и темы
- **Темы:** Светлая, Темная, системная и **настоящий глубокий черный AMOLED-режим**.
- **Кастомизация иконки приложения:** Рыцарский Щит 🛡️, Золотой Кубок 🏆, Дзен Лотос 🪷, Кибернеон ⚡, Пламенный Феникс 🔥.
- **Тональность уведомлений:** «Заботливый друг», «Строгий наставник», «Осознанный помощник».
- **Превью виджета:** Интерактивная карточка виджета для рабочего стола Android.

## 🛠️ Стек технологий и архитектура

- **Язык:** Kotlin 100%
- **UI:** Jetpack Compose + Material Design 3 (M3 Dynamic Color System)
- **База данных:** Room 2.7.0 + KSP (Kotlin Symbol Processing)
- **Архитектура:** MVVM (Model-View-ViewModel) + Repository Pattern
- **Асинхронность:** Kotlin Coroutines & reactive `Flow` / `StateFlow`
- **Анимации:** Compose Transition Animations, Canvas Particles Confetti, Radial Breathing Shimmer
- **Тактильный отклик:** Haptic Vibration Feedback (VibratorManager API 31+)
- **Тестирование:** JUnit 4 + Robolectric JVM Tests

## 🚀 Быстрый старт и установка

### Способ 1: Готовый APK (Рекомендуется)
Скомпилированный файл приложения уже включен в корень репозитория:
- Загрузите файл **`questdo-debug.apk`** из корня репозитория на ваше Android-устройство (Android 7.0 / API 24 или выше).
- Откройте файл и подтвердите установку.

### Способ 2: Сборка из исходников

Требования:
- Android Studio Ladybug / Meerkat или новее
- JDK 17 или JDK 21
- Android SDK 36 (minSdk 24)

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/questdo-android.git
cd questdo-android

# Сборка Debug APK
./gradlew :app:assembleDebug

# Запуск тестов
./gradlew :app:testDebugUnitTest
```

Собранный APK будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`
